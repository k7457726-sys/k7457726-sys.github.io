Privacy policy

Agent backup is a private tool used only by its owner.

  • It requests only the Google Drive scope drive.file, which allows access only to files the tool itself creates.
  • It uploads the owner's backup files to the owner's own Google Drive and reads them back for restore.
  • It does not collect, sell, share or transfer any Google user data to third parties, and does not use it for advertising.
  • Access can be revoked at any time at myaccount.google.com/permissions.
